# Interactive Notes API (Backend)

Серверная часть приложения "Сервис для создания интерактивных конспектов". Реализована на Django REST Framework с использованием PostgreSQL и JWT-аутентификации.


## Основной функционал

Приложение предоставляет REST API для управления образовательным контентом и обеспечивает следующие возможности:

### 1. Управление пользователями и безопасность
*   **Регистрация и аутентификация:** Поддержка создания учетных записей с валидацией данных (email, сложность пароля).
Вход в систему реализован через выдачу пары JWT-токенов (Access и Refresh).
*   **Безопасное хранение:** Пароли пользователей хранятся в хешированном виде.
Секретные ключи и конфигурация базы данных вынесены в переменные окружения.

### 2. Работа с конспектами (Notebooks)
*   **CRUD-операции:** Создание, чтение, обновление и удаление конспектов.
*   **Структурирование контента:** Конспект состоит из разделов (Sections), которые, в свою очередь, содержат блоки контента (ContentBlock). Поддерживаются типы блоков: текст, программный код и изображения.
*   **Совместный доступ:** Владелец конспекта может приглашать других пользователей в качестве соавторов.

### 3. Ролевая модель и разграничение прав
*   **Владелец (Owner):** Имеет полные права на управление конспектом, включая изменение структуры, редактирование контента, управление списком соавторов и полное удаление документа.
*   **Редактор (Editor):** Может просматривать конспект и изменять его содержимое (текст, код), но не имеет права удалять конспект или менять состав команды.
*   **Наблюдатель (Viewer):** Имеет права только на чтение (просмотр) конспекта.

### 4. Тестирование и надежность
*   **Фаззинг-тестирование:** Реализованы автоматизированные тесты, проверяющие устойчивость API к некорректным данным, SQL-инъекциям и попыткам несанкционированного доступа.
*   **Валидация:** Строгая проверка входных данных на уровне сериализаторов DRF.

## Стек технологий
- **Python 3.10+**
- **Django 4.x / DRF**
- **PostgreSQL**
- **Docker & Docker Compose**
- **SimpleJWT** для аутентификации

## Структура проекта
- `interactive_notes/` — настройки проекта и конфигурация.
- `notes/` — основное приложение (конспекты, разделы, блоки, соавторы).
- `users/` — приложение для управления пользователями и регистрацией.

## Тестирование
- `users/tests` - проверка регистрации и аутентификации
- `notes/tests` - фаззинг-тестирование, а также проверка RBAC и валидации

## Локальный запуск

1. Клонируйте репозиторий себе на компьютер:
   - HTTPS
      ```bash
      git clone https://github.com/v-tempe/interactive-notes-server.git
      ```
   - SSH
       ```bash
       git clone git@github.com:v-tempe/interactive-notes-server.git
       ```
   - GitHub CLI
       ```bash
       gh repo clone v-tempe/interactive-notes-server
       ```
2. Скопируйте `.env.example` в `.env` и заполните переменные окружения.
2. Соберите и запустите контейнеры:
   ```bash
   docker compose up --build
   ```
